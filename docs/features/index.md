# 🚀 Features
{: .no_toc }

MusicBee Remote provides comprehensive control over your music playback directly from VS Code.

---

## Core Features

| Feature | Description |
|---------|-------------|
| [📺 Now Playing View](nowplaying.md) | Display currently playing track with album art and metadata |
| [⏯️ Playback Control](playback-control.md) | Control playback with play, pause, next, and previous buttons |
| [🔊 Volume Control](volume-control.md) | Adjust volume and mute/unmute audio |
| [⭐ Track Management](track-management.md) | Rate tracks and mark as favorites |
| [🎨 Themes](../styling/themes.md) | Customize the appearance with multiple built-in themes |
