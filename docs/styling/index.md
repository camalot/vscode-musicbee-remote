# Styling
{: .no_toc }

---

You can customize the appearance of the MusicBee Remote extension by selecting different themes. Each theme changes the colors and styling of the extension's interface to match your preferences or your Visual Studio Code theme.

You can create your own custom themes by defining a set of colors and styles in a JSON file. This allows you to fully personalize the look and feel of the MusicBee Remote extension to match your own aesthetic or to better integrate with your existing Visual Studio Code theme.
